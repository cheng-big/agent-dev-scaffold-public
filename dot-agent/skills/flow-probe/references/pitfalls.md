# 通用踩坑清单（flow-probe）—— 每跑新系统前对照排查

源自多系统业务平台实践，已去项目化、抽象成通用陷阱。

### 坑 1 · 假绿（最严重）
「导航到页面 + 截图 + 直接判 PASS」= 假绿；截图页面可能是**空的**。
→ **修**：每一步都**后端权威回查**——建了就 GET 回查单号/状态，审了就查状态迁移，对外展示就断言 count≥1。断言不成立即 MISMATCH/ERROR。

### 坑 2 · 泳道压平（把跨端流程全塞一个端）
把「公众报名/下单」这种**公众端**步骤，错误地在**管理后台**建单代替。
→ **修**：公众步在公众门户端做（`/public/<域>/*`），审核/编排在管理后台，实名在统一身份，推送在业务中心。**先抽泳道再写**。

### 坑 3 · 审核员分级路由错人
审批按区划分级路由（省/市）。用错账号（超管/无关 admin）打开审核待办 → **待办为空** → 假绿或假红。
→ **修**：省级路由用省级审核员、市级用市级；用审核员身份查待办**真断言 items 含该 bizId/单号**，再点通过、回查状态。

### 坑 4 · 区划门（region scope gate）拒审 403
审核员须区划覆盖被审对象的区划；超管常不在授权列。UI 建单未选「所属区域」→ regionCode 空 → 拒审 403。
→ **修**：确保业务对象 regionCode 落到审核员辖区（探针可 HTTP PUT 补齐作数据准备）。

### 坑 5 · UI 动作「点了没推进却不报错」
提交/审核/发布等行内按钮点击后状态没变、也不抛异常 → 不校验就假绿。
→ **修**：一律用 `uiDrive(uiFn, verifyFn, target)`——点完**校验目标态**，没到判红（不 HTTP 兜底掩盖）。

### 坑 6 · 引用实体下拉（el-select）设不进值 / 偶发不落库
引用字段是 el-select 远程下拉（禁手填）：`.fill()` 设不进去 → 必填校验拦、静默不落库。
→ **修**：`pickRemote(page, dialog, label, text)`（点开→键盘输入过滤→点选项）或点 `.el-select-dropdown__item` 选项。

### 坑 7 · 前后端必填校验口径不一致（真 bug，非探针问题）
表单未把某字段标必填，后端拒空值 → 只填名称提交撞 400。
→ **修**：探针像真人补选必填项（下拉选首项）；同时把「前后端校验不一致」记为 MISMATCH。

### 坑 8 · 创建响应不回显 DB 默认值
POST 返回体可能不含 DB 默认列（如 status DEFAULT '草稿' 但响应回 null）。
→ **修**：断言状态一律 GET 回查权威值，别信 POST 响应。

### 坑 9 · 子记录 vs 主实体
有的迁移端点返回**子记录**（如某审批流水）而非主实体 → 读 `.status` 得 undefined。
→ **修**：迁移后 GET 主实体回查 status。

### 坑 10 · 去重命中旧数据当成新建
公众提交常对 (用户,业务) 去重：已有则返回 alreadySubmitted 且**不新建**。只看 status 会把「命中旧数据」当「新提交」。
→ **修**：断言 alreadySubmitted===false（真新建）+ 回查列表能查到该单号。撞去重就换干净账号或换业务对象。

### 坑 11 · SPA 同路由复访不重新挂载（高频）
Playwright `page.goto('/#/同一路由')` 在 SPA 里不触发组件重挂载 → 拿到**旧列表**（如审核第 2 次访问同页看不到新数据）。
→ **修**：同上下文复访同一后台路由，goto 后 `await page.reload({waitUntil:'networkidle'}).catch(()=>{})` 强制重挂载。（lib 的 auditTodo/uiRowAction 已内置 reload。）

### 坑 12 · 行匹配用了表格没有的列
按 rowText 定位行时，用了**表格里不存在的列**的值（如按"时段"匹配但表格无时段列）→ 永远匹配不到。
→ **修**：先看 vue 的 `<el-table-column prop=>` 确认可见列，用可见且唯一的列（单号/编号）匹配。

### 坑 13 · submit-approval 只建审批实例、不改业务状态
点「提交审核」后业务对象 applyStatus 没变（仍"待提交"）——因为提交只创建审批实例，状态要到审核才变。用业务状态校验会误判失败。
→ **修**：校验「审批实例已建」（回查审批实例列表按 bizId 匹配），别指望业务状态立刻变。

### 坑 14 · 审核「通过」弹框有无 prompt 不一致
有的系统审核待办「通过」带 ElMessageBox.prompt（须填意见+确定），有的「通过」直接办结（只有驳回才弹）。
→ **修**：helper 对弹框用 `try`/optional 容错（lib 的 auditTodo 已做：有弹框就填+确定，无则跳过）。

### 坑 15 · 有头多窗口偶发页面被关闭 / 监控刷屏
`HEADLESS=false` 多上下文（管理端+审核端+门户）偶发 page/context closed；探针步骤刷屏会把监控自动停。
→ **修**：门户导航全程 try/catch 不抛；**出正式报告用 headless**（引擎渲染一致），有头仅供肉眼看；等长任务用轻量 `until grep 终态标记` 而非刷屏 tail。
